# Frontend Design Rule: Cohere-Style Enterprise Design System

All frontend and UI components created in this project MUST strictly adhere to the Cohere Design System documented in [docs/design_system.md](file:///e:/Intern_Presentation/Hiver%20Project/docs/design_system.md).

## Core Principles
1. **Editorial Restraint & Sober Enterprise AI Tone**: Flat elevations, generous whitespace, austere black-and-white foundation with purposeful dark green (`#003c33`) or dark navy (`#071829`) capability bands.
2. **Typography**:
   - Display: Tight line-height (1.00), negative letter spacing (-1.92px to -0.48px). Space Grotesk / Inter fallback.
   - Body: Inter / system-ui, measured 14px-18px.
   - Technical / System: Monospace labels in uppercase with tracking (`0.28px`).
3. **Color Palette**:
   - `Canvas White`: `#ffffff`
   - `Near-Black Primary`: `#17171c`
   - `Cohere Black`: `#000000`
   - `Deep Enterprise Green`: `#003c33`
   - `Dark Navy`: `#071829`
   - `Coral Accent (Taxonomy / Badges only)`: `#ff7759` / `#ffad9b`
   - `Action Blue`: `#1863dc`
   - `Soft Stone`: `#eeece7`
   - `Hairline / Border`: `#d9d9dd` / `#e5e7eb` / `#f2f2f2`
4. **Shapes & Radii**:
   - Pill CTAs: `32px` (`button-primary`)
   - Media / Console Cards: `22px` (`lg`) or `8px` (`sm`)
   - Filter pills / Chips: `30px`
5. **No Decorative Gradients**: Gradients are media-led only; UI surfaces must remain flat.
6. **No Emojis**: Use SVG/library icons or clean typography badges.
